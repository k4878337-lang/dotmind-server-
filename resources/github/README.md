# DOTMIND GitHub Reference Resources

This directory contains curated references and skill links for the DOTMIND Personal AI Agent.

### 📱 Android & Jetpack Compose
- **[compose-samples](https://github.com/android/compose-samples)**: Official Jetpack Compose samples (Jetcaster, Jetsnack, Crane, Reply) demonstrating UI architecture, state hoisting, animations, and dark theme implementations.
- **[nowinandroid](https://github.com/android/nowinandroid)**: Fully functional Android app built entirely with Kotlin and Jetpack Compose adhering to modern Android architecture guidelines.

### 🌐 Web & Full-Stack
- **[next.js](https://github.com/vercel/next.js)**: Production-grade React framework with server-side rendering, SEO-optimized metadata, and dynamic routing.
- **[tailwindcss](https://github.com/tailwindlabs/tailwindcss)**: Utility-first CSS framework for responsive website styling and layout designs.

### 🔌 Usage by DOTMIND Agent
These references are mapped into the `SkillsCatalogue` under `android-development`, `website-seo`, and `mobile-animations`. When a user requests Android UI or website architecture, the agent leverages the design patterns from these official resources without bloating the installed Android APK size.
